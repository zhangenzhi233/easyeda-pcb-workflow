# 从交付版本验收

先对设计规格核实电气意图，再比较原理图、板和制造文件是否一致。检查文件要来自同一板号、修订和装配变体。以下脚本均只读，命令中的脚本路径相对本技能目录。

## 从原生走线找待看片段

`review_routes.py` 可直接读专业版的 `.epro2`、`.epru` 或 `.epcb2`。多块 PCB 放在一个包内时用 `--pcb` 指定文档 UUID 或唯一标题。用坐标、网名、层和对象 ID 回到原板复查。

```shell
uv run --no-project scripts/review_routes.py "主控板.epro2"
```

工具按同层同网的直线中心线识别两段直角（内角 88°～92°）、锐角回折和共线重叠，分开统计多路分支和中段接入。需查碎线时加 `--short-mm` 和本次筛查长度，例如 `--short-mm 0.35`。这是找图的门槛。直线计入焊盘和过孔内的端点，圆弧、铺铜及焊盘铜形还要按[实际回路](routing-review.md)在 CAD/CAM 判读。退出 0 表示已做列明的几何扫描，结果看 `counts`、`candidates` 和 `unanalysed_copper_objects`。退出 2 表示输入无法完成扫描。

## 检查原理图与 PCB 的真实网络

1. 在分别激活的文档里独立导出两份嘉立创 ENET 2.0.0。两图一致也可能同错，从手册、线束或接口表另录一些已确认的关键脚，可用以下 CSV 格式。针号按原字符串记录，BGA 焊球如 `A1`、`B2` 同样适用。示例中的位号与网络需换成本板数据。

```csv
ref,pin,net
J1,1,VIN
J1,2,GND
```

2. 运行标准库脚本。没有独立针表时省略 `--expect`，此时结果只覆盖两份文件之间的一致性。

```shell
python scripts/compare_enets.py "sch.enet" "pcb.enet" --expect "pin-table.csv"
```

3. 按位号、物理脚号检查两个方向，输出 JSON 含两份输入哈希、脚数、网络数和具体差异。`0 match` 表示当前覆盖一致，`1 different` 表示存在需定位的差异，`2 review` 表示输入或证据不足。有差异和疑项并存时读完 findings。相同字节、可识别的来源类型与输入侧冲突、工程身份不明、编号重叠、未知网络、空清单和未分配位号需复核。若封装库标识缺失或两边有异，即使所有针脚网络一致，也提示检查封装及变体；标识相同仍需对照手册验证焊盘几何。
4. `@NC` 是独立针表内用于已核实悬空脚的记号，只有明确存在且网名为空的脚才与它匹配；先查手册，再声明。只跳过原理图中明确设置了 `Convert to PCB = no` 的纯逻辑对象，并报告列表。DNP 是装配属性，有焊盘的器件仍要检查。多单元共脚、机械占位、net-tie、同号多焊盘等特殊模型应以原生库和制造物理脚逐一复核，记录覆盖范围。

## 检查丝印碰窗和实际板面

用独立 CAM 查看器打开准备送厂的 ZIP，按成品正面及背面视角核对 1 脚、极性、接口名、针表、位号遮挡和板边。工具里同时显示同一面的丝印与阻焊**开窗**。底层在编辑器顶视与成品底视的朝向不同。

可选脚本声明了独立运行所需的 `gerbonara==1.6.3`、`shapely==2.1.2`。装有 uv 时可直接运行下列命令，依赖进入隔离的缓存环境。若已有这些包，也可用 Python 3.10 或更高版本直接运行同一脚本。板厂给出丝印离窗间距时可加入 `--clearance-mm 实际数值`，省略时只检查面积重叠。

```shell
uv run --no-project scripts/check_silkscreen.py "Gerber.zip" --side both
```

脚本按 GTO/GTS、GBO/GBS 匹配单板丝印及开窗，按文件单位和明暗图元计算面积，给出重叠位置（mm）。`0 clear`、`1 violation`、`2 review`。读取各面结果，`no_printed_ink` 表示该面没有印字。缺层、重复候选、暂不支持的格式或解析告警会标待复核。曲线按 0.0001 mm 弦误差近似，处于工艺边界时用板厂 CAM 核实。

若要逐字自动比对，可加 `--labels-json 字形基准.json`。由已核对的原生位号、功能针表与实际字体轮廓生成参考，保存位置、旋转及面别。顶底均用同一组从顶面看的板坐标，底面轮廓先按实际翻板关系转换一次。可对同一份双面清单用 `--side top` 或 `--side bottom` 单查一面。参考与待检 Gerber 应独立取得。无法取得可靠轮廓时，按[丝印摆放与实图审查](silkscreen.md)逐字查成品图。

JSON 顶层为 `{"unit":"mm","view":"top","labels":[...]}`。每项含唯一标识 `id`、`side`（`top` 或 `bottom`），以及 `ink_wkt`（Polygon 或 MultiPolygon 文本）或 `ink_wkb`（同类几何的十六进制 WKB）。使用完整字形，包括笔画与字内空白。脚本在每个词的外接矩形加坐标容差范围内比对缺少和多出的墨迹，报告错项 ID 和位置。该窗口应只含对应文字。默认坐标容差 0.005 mm，用 `--xy-tolerance-mm` 可按导出精度调整，容差须远小于最细笔画和行距。报告的覆盖数限于清单内的词，仍需按逐针表核实语义、检查清单外多印的字和装件后的可见性。

## 判定是否可以送样

若用户交来一份原始告警清单，保留每项的类型、网名、位号和脚号。逐项关联改动及复开后的证据。未接脚应在两份原生网表和成品导电区域中找到预期对端，故意 NC 则与手册核定。报告原始总数、已关闭、已解释和待办数量，再列本次 ERC 与 PCB DRC 的实际结果。

有芯片裸露底盘或裸铜测试点时，单独打开最终锡膏层（GTP/GBP），量底盘分窗数量和覆盖面积，逐个确认指定免锡膏测点的开口面积为零。发生过原生导出将默认焊盘闪绘叠在自定义开窗上的情况。出现叠加时修封装或校正本次钢网输出，记录原始与修正包，逐层确认其他制造图形一致，并复查每个受影响窗口。

| 打开什么 | 实际要核对什么 | 发现问题后 |
|---|---|---|
| 交付工程 | 对原理图、PCB 分别保存、复开。复查原生 ERC、DRC、未布通数、关键器件真实位置和引脚。 | 按位号/坐标改源。记录错误、警告以及经解释的例外，复开后再查，回执缺失写明未证实。 |
| 制造铜与钻孔 | 对照板框和机械图测外形、孔位、孔径。检查所有铜层、孔环、阻焊桥、铜到边和铣槽。PTH 与 NPTH 分开；Via-only 有时是 PTH 的子集，先查坐标避免重复计数。 | 对互连验收用 CAM 连通提取、IPC-D-356 或对应板厂 DFM/网表比较，记录覆盖的网络与层。普通两层通孔板可按每面铜岛和真实 PTH 跨层追踪；盲埋孔要按实际起止层，内电层要解析极性和避空。 |
| 接口与装配 | 从原理图针表追到 PCB 焊盘、飞针坐标与正反面丝印。有装配任务时核查 BOM 中料号、封装、数量、DNP 和坐标中的位号、面别、角度、原点。 | 飞针表可验证制造数据中的引脚标注。实际铜是否开短路仍由铜层及孔连接分析检查。极性、配对和镜像也用实物视角核对。 |
| 仿真或样机 | 写明输入、负载、边界工况、模型与测点。先定义可接受范围，再对照波形、启动或热结果。实物阶段记录仪器接法与限流、实测值。 | 将尚无证据的性能列为待测。送样以电气、结构和制造的关键问题均有结论为条件；物理样机可行性随实测更新。 |

**留给下一位设计者的记录。** 对关键问题用一行写出“对象与工况 / 预期或来源 / 实际测量 / 工程修订与证据文件 / 结论”。例如，发现阴极条覆盖开窗时记录是哪一面、哪个器件、多少 mm²，回到封装或板图修正，再用重新导出的 ZIP 复核。用户只问某处 GND 时，从该引脚、网表、铜层到最近真实地端说明结果即可。
