# 嘉立创 PCB 绘制与验收

先弄清供电、信号、接线和测量方法。已有板先读回用户正在看的工程，核对板号、修订以及尚在编辑器里的手工调整。只审图时指出具体器件、网络或针脚。获准改板时把修改落到可编辑源，并复验最终出图。

用户圈出一个拐点、地线或位号时，先按焊盘号和所在层认清对象。布线或排版优化默认用同一判据复查全板相关网络、接口和对称通道，记录改动及有依据的例外。用户明确限定局部时按指定范围处理。

- 发现直角、V 形折返、碎线、重叠、地线串接或驱动窄颈，按[全板走线与回流复查](references/routing-review.md)定位、修线、重铺和复核。
- 调整位号、接口针名及孔位丝印，按[元件与接口丝印摆放](references/silkscreen.md)做上下居中、逐孔对齐和正反面成品核对。

## 从电路到板面

| 阶段 | 实际操作 | 进入下一步前看什么 |
|---|---|---|
| 约束与器件 | 列电源范围、负载、接口针序、板框、孔位、插拔方向、装配方式。按完整料号查手册，把符号针号、封装焊盘号、一脚和极性对到同一视角。 | 能沿一个关键接口逐针找到芯片或电源端。记录关键数据的来源与待实测尺寸。已有板先存基线。 |
| 原理图 | 按功能和信号方向分页分组。电源、地、短网标用真实电气对象；关键支路就近连线，跨页用同名端口。把默认上拉、选装和测试点写在对应器件旁。 | 高亮一个电源、一条跨页网和一个接地脚，观察实际成员。用导出 PDF 的整页视图读一次接口针号、位号和数值，消除长折返、压线、叠字。 |
| 布局 | 先定连接器、安装孔、板边与禁占区，再在主芯片周围摆好每个局部电路，最后调整模块间位置。沿实际焊盘看电流去路与回路。 | 量插头和螺柱净空，指出一个去耦或开关回路和一个敏感信号路径。选中最难出线的一组，看扇出和换层空间；拥堵就回移元件。 |
| 规则与布线 | 依据板厂当次叠层、工艺及芯片/接口规范建网络类。先布限制最强的网络，再完成普通信号与电源。交付前恢复被临时隐藏的飞线，重铺所有相关铜区。 | 在真实网络上读回生效的宽度、间距与参考面；追踪关键网到达目标焊盘和回流的连续路径。存在约束的信号记录端点、组别及允许值。 |
| 丝印与操作 | 按器件视觉中心摆放位号，接口按实际脚号排字，保留装件后要读的功能标记。 | 从元件面和实际翻板后的背面逐针读一遍，在制造文件量字形和开窗间距。 |

原理图、放置和层叠取舍按板型查[绘图手法与板型分支](references/drawing.md)。某项结论有争议时，可回看[课程操作时间与方法出处](references/sources.md)。

## 在嘉立创中执行

先核对正在操作的客户端、工程、板、文档类型与标识。使用官方 API 或指定的 easyeda-agent 通道，写入同一文档的操作串行执行。选择命令、处理单位以及保存、复开、回读的方法见[工具操作](references/editor.md)。超时或部分成功时，先读已有对象和保存状态，再决定重试哪些变更。

## 交付前，从最终文件复查

1. **电气。** 先审从原理图导入 PCB 的变更清单，再应用变更、重铺、跑 ERC / DRC，分别记录错误、警告、经核实的例外及未完成项。保存并用交付文件复开，再导出两份独立网表。用位号与实体脚号逐项核对。另从手册或已确认针序检查关键脚，防止两张图一起画错。
2. **制造。** 从同一版生成需要的 Gerber、钻孔和装配资料。在 CAM 查看器里直接打开制造包，核对板框、各铜层、PTH/NPTH、正反面丝印、阻焊开窗、孔环和铜到边。对关键网络追到最终铜，跨层处应有实际金属化连接。[验收与可运行工具](references/verification.md)
3. **功能。** 根据这块板的用途选工况与测点，例如上电、负载变化、复位或信号响应。仿真记录模型、输入、负载、预测范围；实测记录仪器、接法和读数。没有实物时给出可以照做的台架步骤。
4. **交付。** 按用户范围提供可编辑工程、可放大的原理图、能看清布局和布线的板图，以及实际生成的生产或验证文件。指出已通过、需人工判读、待打样实测的项目。有烧板风险的未决项要具体到位号、焊盘或网络及其影响。用户指定某项先给他看时，在约定位置展示；其余工作按已有授权推进。

修改后复查因果链。例如移动输入电容后重看电源回路、铺铜、间距和对应装配图；修改针序后同时复核符号、封装、原生网表、板边文字和已生成的制造文件。
