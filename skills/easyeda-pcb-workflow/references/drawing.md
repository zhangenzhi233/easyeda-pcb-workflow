# 原理图、放置与布线

## 从图纸验证意图

- 参考成熟开发板时，沿用其分页、信号流向、接口编号和读图方向。对新主控逐页查实供电与去耦、晶振与负载电容、复位有效电平、启动绑带在采样时的电平，以及下载口的参考电压、地和键位。把各项对应到新芯片的实际封装脚号和可测节点。
- 先画供电、复位/启动、时钟与下载的最小电路，再接外设。每个电源域写电压和来源，开漏和故障脚写默认状态。两个相似通道用同方向、同针序的符号，差异写在发生处。
- 同页能用一小段线看清的连接保留导线。导线要穿过无关模块才能接到目的地时，在两端放有电气属性的网标/端口。检查标签作用域、线端吸附、T 结点和交叉点。接口地脚可就近拉出短线接原生地符号，网表中核对这只脚和目标地脚都属于预期地网。
- 普通说明文字只负责解释。候选符号若把所有引脚都设为无源，ERC 的电气类型覆盖会变差。对照器件手册检查电源、输入、输出、开漏及未用脚。指定悬空、保留脚、裸露焊盘和可选元件分别按手册和默认装配状态处理。
- 把 PDF 按预定纸张整页看一次，再放大关键块。应能在需要的阅读尺度分清针号、阻值、地符号和连接点。文字与引线相压时，先缩短跨区引线、移动标签或拆页，再调字号。电气连通和人能读清分别复核。

## 从接口向内摆件

1. 在板框上锁定有依据的位置。把插头的插拔行程、拧紧空间、螺丝头、排线弯折及探头位置放进视图。没有实物尺寸时先标范围和依据。
2. 从原理图交叉选择一个功能块。先把芯片、对应阻容和必要过孔排成局部电路，再将整组放上板。让同类端口的方向有规律；针序受协议或现有线束约束时保持原定义。
3. 用实际引脚核对摆放。例如从去耦电容电源焊盘走到 IC 的 VDD，再从 IC 的 GND 和邻近地铜/过孔回到电容。开关电源分别追导通、续流路径并检查高 di/dt 换流环路，反馈按手册指定的安静点取样，远离 SW 节点。模拟前端看敏感节点面积、参考地和与开关边沿的距离。
4. 走关键线前比较一两种可行朝向。优先解决接口净空、交叉、扇出和回流。走到某处需要长支路或绕开一排过孔时，回到源布局比较旋转、移位后的效果。用同一对端点、同一视角、同一单位保存前后证据。焊盘直线距离、实际走线长度和回路面积分别记录。
5. 从板边看一遍操作顺序。针座 1 脚、极性和组别至少有清晰对应关系；底面字按实物底视读，组装后被插头覆盖的功能名移至可见边。规则最小字高、线宽及离窗距离取本次板厂能力。

## 按网络与板型决定走法

| 情形 | 做法 | 怎样确认 |
|---|---|---|
| 双层 MCU、模拟或电源小板 | 让一面尽量保有连续地铜，先画噪声源、敏感节点及测量口。为时钟、反馈和去耦留近路。给成组的排针按引脚次序留扇出空间。 | 两面重铺后高亮地，追一条高速边沿或大电流的去路和返回路径，检查底层长线、禁布区和孤岛。地孔位置按实际路径定。 |
| 四层 MCU、外部存储或多接口 | 先选板厂可做的叠层、确认每个信号层实际参考的铜。建网络类识别 SDRAM 数据组、地址/控制、时钟和 TF 等。带支线者明确源、目标与分支，先连通、修线，再按预算调长。 | 点中一个焊盘对，核实软件监测的是该段。底层若参考电源层，沿全程检查分割和电源交流回流条件。 |
| 六层 BGA、DDR 或高速差分 | 先估算 BGA 行列、孔型、出线通道及放去耦的空间，再定层数与可制造层叠。登记每组参考层与时序预算。DDR3 按控制器定义组织 DQ、DM、对应 DQS，各自处理时钟及地址命令组。HDMI/USB 等按对应接口型号和速率建差分规则。 | 检查实际逃线、每对耦合与对内偏斜、规定的组间匹配和接收端参考。换层时就近提供适当回流通路；两块同网地平面之间可布回流地孔。不同参考电位之间按电源和信号完整性设计处理。 |

**规则的依据。** 线宽与孔数取决于电流、铜厚、温升和最窄处；阻抗取决于所在层、介质、铜厚、参考面和差分几何；等长窗口取决于器件、协议和端点预算。把这些来源、单位与当前规则名称一起记下。课程里的 0 Ω 分地、晶振禁铺、3W、固定 mil 数和蛇形线只在满足相应条件时使用。一般低速网做好可追踪、间距和返回路径即可。
