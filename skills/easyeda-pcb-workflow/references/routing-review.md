# 从一处走线复查到整板

从用户指出的区域开始。在编辑器中单独显示该铜层，高亮网络，查实际焊盘号、过孔起止层和铜线宽度。白色高亮圆点可能只是线段端点，叠层视图里两条相交的线也可能分属两层。先判断那里是折点、分支、焊盘入线还是实际换层。

## 找同类走线

| 在板上看到什么 | 怎样修改和确认 |
|---|---|
| 一条网走出楼梯状小折线、V 形折返、直角，或绕过同网相邻引脚再折回来 | 固定真正要连接的焊盘、过孔和分支。普通信号优先用水平、垂直和 45° 斜段，以尽量少的转弯连通。一起查看焊盘或过孔里面藏着的最后两段。晶振、差分、等长补偿和障碍旁的扇出应先满足各自的电气约束。 |
| 节点像团块、斜线刚出盘就回头、一段线上叠另一段 | 分辨两段转角、三路以上的真实分支和同层重叠。小器件对准焊盘有铜区域入线，把分支收到明确的位置，能合并的共线重复段合并。保留测试点、有效并联载流路径、裸露焊盘的多路宽引出。删除前后逐点核实端点和过孔都已接上。 |
| 主控密脚附近很挤 | 先看去耦电容、晶振和负载电容能否靠近对应引脚或换朝向。相邻同网脚可用短主线逐脚接入，电容回流走近路。模拟参考与数字电源有独立网络或滤波元件时，保持规定的连接位置。 |
| 驱动管附近看起来很宽，端子、分流器或换层处却缩成细颈 | 按正反转或实际导通状态，从每个电机端子分别追到高侧、低侧管，再追电源和回流。量整条成品铜中的最窄处、焊盘入线和换层孔组，比较对称通道。栅极驱动、保险前后测点及分流采样各走自己的支路。按器件手册从分流电阻焊端引出 Kelvin 取样，避免把载流铜上的压降算进读数。线宽与并孔要结合铜厚、峰值电流、温升及孔工艺。 |

用户指出的是整类画法时，用同一条件扫所有网络、铜层及镜像通道。可用[原生走线扫描工具](verification.md)定位。普通两段转弯按夹角判断，去程与回程在同一点构成的小夹角是折返，180° 是直行。记录候选的网名、层、坐标和关联器件，检查异层交叉、分支、故意调长和焊盘扇出的用途。按本板目标修正或注明保留原因。交付时给同一面、同一比例的改前改后局部图，连同全板复查的范围。

## 决定哪段地线可以交给铺铜

1. 查焊盘、铺铜区、孔的实际网络与层叠。普通地焊盘在同一连续铜区时可直接接入，就近接地过孔可缩短到参考面的回路。安装孔要查金属化、电气分配和孔跨层。隔着避空环的孔或未连接的孤岛不能承担这条回流。
2. 先打通候选的新回路，再分支路精简旧地线。保留开关电源输入电容的高频回路、驱动器旁路、功率桥回流、分流器的取样返回和芯片裸露焊盘需要的宽短连接。在双层板上尤其检查信号线对地铜的切割。局部无连续参考铜时，补短地线、调整过孔或回到布局解决。
3. 重铺、保存、复开。沿**地焊盘 → 本层实际铜区 → 有效金属化孔 → 连续主地铜**逐段核对。器件通孔也可能提供连接。若经小铜岛和其他层中转，记下中转位置。高频或大电流还需看回路面积、窄颈、过孔到焊盘的距离和承载能力。仅凭同网高亮、地孔总数或地线变短，不能证明回流质量。

例如，主控去耦可以就近入地，降压输入电容与芯片之间仍需要短回路。同是标为 GND 的焊盘，处理方法取决于流过它的电流。[英飞凌 TC2xx 硬件设计指南](https://www.infineon.com/assets/row/public/documents/10/42/infineon-ap32469-tc2xx-hardware-design-guide-applicationnotes-en.pdf) · [TI DRV8701 布局指南，第 10 节](https://www.ti.com/lit/ds/symlink/drv8701.pdf)
